date: 2026-11-04

**PinePods 0.9.2** is a quick patch for 0.9.1. **If you're on 0.9.1, please upgrade.** Some podcasts stopped playing on every client, and this release fixes them automatically.

> **Before you upgrade:**
> * **The first refresh reads every feed in full once.** It takes longer than usual once, and it's how episode links get repaired.
> * **The iOS app now requires iOS 15 or later.**
> * **Check your server downloads if you use them.** See below.
>
> The [release notes](https://github.com/madeofpendletonwool/PinePods/releases/tag/0.9.2) have the details.

---

## Episodes That Wouldn't Play

* **The problem** – 0.9.1 could save the wrong link for an episode, or no link at all, so it would fail to play. This came from a feed-parsing library update and affected podcasts whose feeds include extra media tags, such as Stuff You Should Know. Other feeds weren't affected.
* **The fix** – After you upgrade, the first refresh puts the correct links back. You don't need to do anything, and your listening history stays on the same episodes.
* **Server downloads** – Episodes from affected feeds downloaded to the server on 0.9.1 may have saved a web page instead of audio. These aren't replaced automatically, and the [release notes](https://github.com/madeofpendletonwool/PinePods/releases/tag/0.9.2) show how to find them. Delete any you find in Pinepods and download them again. Server downloads now refuse web pages, so this can't happen again.

---

## Other Fixes

* **Add People** – You can type spaces in names again on the web.
* **OIDC login** – When a login can't start, the login page now shows the reason instead of appearing to do nothing.
* **Podcast descriptions** – The mobile apps no longer show HTML tags like `<p>` on podcast pages and in search results.
* **Failed playback on iOS** – An episode that can't play now shows an error and a retry button instead of spinning forever.
* **Mobile theme picker** – Fixed a theme mismatch that could leave the picker blank and show the wrong theme.
* **New users** – New accounts now start on the Nordic theme, matching every other way of creating an account.

---

## Under the Hood

* **Mobile** – Flutter 3.47.9, a newer Android build toolchain and updated packages.
* **IzzyOnDroid** – Removed the embedded build ID that failed the reproducible build check.
